# xlam_agent: external-validity benchmark agent

An [ADK](https://adk.dev/) benchmark agent built from the 100 most-called tools in
[`Salesforce/xlam-function-calling-60k`](https://huggingface.co/datasets/Salesforce/xlam-function-calling-60k),
used to measure `adk-smart-router` on third-party tool schemas and third-party queries with a
ground-truth answer key.

## On-demand dataset fetch

Because `Salesforce/xlam-function-calling-60k` is distributed under CC BY 4.0 and gated on Hugging
Face, the generated `tools.py` and `queries.jsonl` files are not redistributed in this repository.
Generate them locally on demand before running the `xlam` benchmark scripts:

```bash
export HF_TOKEN=hf_...   # after accepting the dataset terms on Hugging Face
uv run python scripts/build_xlam_agent.py --fetch
```

This downloads `xlam_function_calling_60k.json` from Hugging Face into `.xlam/` and generates:
- `examples/xlam_agent/tools.py` — 100 deterministic Python tool stubs whose function names,
  parameter signatures, and docstrings come directly from xLAM's tool schemas.
- `examples/xlam_agent/queries.jsonl` — the 15,786 queries whose ground-truth tool calls fall
  entirely within those 100 tools.

## Layout

| Path | What |
| --- | --- |
| `agent.py` | Root `LlmAgent` named `xlam` on `gemini-2.5-flash`. |
| `instruction.py` | Neutral assistant instruction sized above the model's context-cache floor. |
| `run_agent.py` | Local runner wiring `SmartRouterPlugin` ahead of `BigQueryAgentAnalyticsPlugin`. |
| `tools.py` | *(Generated by `scripts/build_xlam_agent.py --fetch`, gitignored)* |
| `queries.jsonl` | *(Generated by `scripts/build_xlam_agent.py --fetch`, gitignored)* |

## Running the benchmark

See [`docs/scenarios.md`](../../docs/scenarios.md#very-large-surface) and
[`docs/evidence.md`](../../docs/evidence.md) for the measured results and commands:

```bash
# Offline tier comparison (Cold-Start PrototypeJudge vs. Trained XGBoost vs. Hybrid)
uv run python scripts/score_sets.py --agent xlam --session-prefix xlam-c1- --compare-tiers

# Answer-key quality evaluation across holdout and routed arms
uv run python scripts/score_xlam_answers.py --session-prefix xlam-ab1-
```
