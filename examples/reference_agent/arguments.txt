# The reference agent's 74 required-argument names, marked by whether a customer
# holds the value. Written by hand from the tool docstrings; this is the ten
# minutes the router asks of an adopter, done once so there is a worked example.
#
#   smart-router qualify --app examples.reference_agent.agent:root_agent \
#       --arguments examples/reference_agent/arguments.txt
#
# It comes back 66 reachable and 34 second hop. Checked against the corpus, 45 of
# the 48 tools that were ever a session's first call are in the reachable 66, and
# the 34 second-hop tools account for 5 first calls out of 1,412 sessions.
#
# The nine `held` lines carry the whole result and each is a judgement, not a
# pattern. `sku` is held because the shop assigns it and `order_id` is supplied
# because the customer was emailed it, and nothing in either schema says so. The
# ones that took the longest were `account_id` (business customers do quote it,
# so supplied) and `reservation_id` (the customer is given the reference, so
# supplied). Getting one of these wrong moves whole blocks of tools at once,
# which is why the list is ordered by how many each gates.
